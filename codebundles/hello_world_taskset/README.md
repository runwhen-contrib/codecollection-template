## Usage
- `ro runbook.robot` ==> this will use the default value against the `MY_INPUT` Suite variable.
- `MY_INPUT="Alan Walker" ro runbook.robot` ==> this will execute the task with the Suite variable `MY_INPUT = "Alan Walker"`
